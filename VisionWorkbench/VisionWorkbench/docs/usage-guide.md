# VisionWorkbench 使用说明

## 1. 整体框架

VisionWorkbench 是一个面向产线视觉检测的 WPF 应用，整体分成四层：

- `主页`：运行态看板，显示相机画面、检测结果、报警、日志。
- `配置层`：型号管理、任务设置、模型训练库、相机设置、参数设置。
- `运行层`：扫码枪、IO、相机采集、模板对齐、CLIP 分类、测量、结果落库。
- `数据层`：配置文件、模板库、向量库、检测记录库、图片归档目录。

建议的使用顺序是：

1. 配相机
2. 建型号
3. 注册模板
4. 配任务
5. 建训练库
6. 开始检测
7. 用数据查询复盘

## 2. 启动流程

软件启动后会自动完成这些事：

- 读取 `RuntimeData` 下的配置和数据库
- 初始化扫码枪、IO 模块、相机对象
- 恢复已保存的型号、任务、模板、训练库
- 启动后台生产循环，但只有点了 `启动` 后才进入实际检测

正常情况下，启动后你先做配置，不会立刻进入生产检测。

## 3. 目录结构

默认根目录为 `RuntimeData`，现场迁移时只要拷贝这一棵目录即可。

常见子目录如下：

- `RuntimeData/Config`：配置文件
- `RuntimeData/Models`：CLIP 模型文件
- `RuntimeData/Cache`：向量库、训练缓存
- `RuntimeData/Database`：对齐模板库、检测记录库
- `RuntimeData/InspectionImages`：原图、Crop 图归档
- `RuntimeData/Products`：型号相关的模板图、训练样本、资产

图片归档默认主目录目前可在参数设置里调整。

## 4. 配置流程

### 4.1 相机设置

进入 `相机设置` 后，按下面顺序配置：

1. 选择相机
2. 选择设备
3. 设置触发模式
4. 连接相机
5. 保存相机配置

说明：

- `拍照`：手动采一张图，常用于离线调试
- `读取图片`：从本地载入一张图，常用于离线测试和定位问题
- `连接/断开`：管理当前相机状态

### 4.2 参数设置

进入 `参数设置` 后，主要是查看和调整运行路径：

- `Root`
- `配置目录`
- `模型目录`
- `缓存目录`
- `数据库目录`
- `CLIP 模型`
- `向量库`
- `对齐模板库`
- `检测记录库`

其中图片归档目录可以单独保存。

### 4.3 型号管理

`型号管理` 用来维护产品型号和每个相机的模板参考图。

建议流程：

1. 新建型号
2. 为每个启用相机拍一张模板图
3. 点击 `创建`，生成对齐模板
4. 必要时调 `MaxLongSide`、`MaxFeatures`、特征方法等参数
5. 模板稳定后再进入任务设置

型号管理里比较重要的约束：

- 成品号唯一
- 名称唯一
- 删除型号时会联动清理相关任务、模板和训练资源

### 4.4 任务设置

`任务设置` 用来维护该型号下每个相机的检测任务。

核心流程：

1. 选成品号
2. 选相机
3. 选择 `模板编辑` 或 `测试预览`
4. 新增任务
5. 画 ROI
6. 调任务参数
7. 保存配置

说明：

- `模板编辑`：用于修改 ROI 和任务参数
- `测试预览`：用于看拍照/读图后的对齐效果，ROI 不允许修改
- ROI 目前按三点方式绘制，完成后回写中心点、宽、高、角度
- `Measurement` 类型任务会显示测量面板和 `Profile` 按钮
- `Classification` 类型任务会进入 CLIP 分类流程

### 4.5 模型训练库

`模型训练库` 是 CLIP 分类样本维护页面。

建议流程：

1. 选成品号
2. 选分类任务
3. 选择样本模式
4. 导入或补充 OK / NG 样本
5. 必要时测试推理
6. 调 `TopK` 和 `Threshold`

样本模式有两种：

- `ROI 图`
- `整图对齐裁 ROI`

常用操作：

- `OK / NG` 样本右键切换标签
- 候选样本可一键确认入库
- 模板图会自动作为初始 OK 样本来源之一

## 5. 运行流程

正常生产时的主流程是：

1. 点击 `启动`
2. 后台循环开始监控 DI 触发
3. DI0 或手动触发触发一次检测
4. 扫码枪填充成品号、序列号
5. 相机拍照或读取原图
6. 按成品号找到模板并对齐
7. 依次执行该相机下所有任务
8. 结果写入检测记录库
9. 原图和 Crop 图按日期归档

按钮含义：

- `启动`：进入运行态
- `停止`：退出运行态
- `手动触发`：手动执行一次完整流程
- `采集`：单相机测试触发

## 6. 结果查看

`数据查询` 页面用于查看历史检测记录。

可筛选条件：

- 时间范围
- 成品号
- 序列号
- 相机
- Task
- 结果
- 是否只看最近 100 条

常见用途：

- 查某个成品号的历史良率
- 查某次 NG 的原图和 Crop 图
- 按任务回溯参数和判定分数

## 7. 图片与数据保存

检测触发后会保存：

- 原图
- 任务 Crop 图
- 检测结果
- 检测日志

建议现场交付时重点备份这些目录：

- `RuntimeData`
- 图片归档目录
- `InspectionImages`

## 8. 常见问题

### 8.1 为什么没有检测结果

先看这几项：

- 成品号是否已选中
- 当前相机是否已连接
- 对齐模板是否已创建
- 扫码枪是否有值
- DI 触发是否正常

### 8.2 为什么 ROI 不生效

常见原因：

- 还在 `测试预览` 模式
- 当前任务没有选中
- 模板图未注册
- ROI 超出图像范围

### 8.3 为什么模型训练库为空

先检查：

- 当前成品号是否正确
- 是否选中了分类任务
- 训练库是否切到正确样本模式
- 该任务是否已经生成过 OK 样本

## 9. 建议的上线顺序

最稳的上线顺序是：

1. 先配相机
2. 再建型号
3. 再注册模板
4. 再配任务 ROI
5. 再建 CLIP 样本库
6. 最后切到运行状态做联调

这样排，出问题时也更容易定位到底是相机、模板、任务，还是训练库的问题。
